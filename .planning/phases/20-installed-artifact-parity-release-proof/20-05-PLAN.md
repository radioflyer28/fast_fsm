## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build artifacts → matching native jobs | Cross-runner artifacts can be swapped, routed to the wrong architecture, or counted without execution. |
| downloaded evidence → aggregate | Artifact names/globs can hide duplicates, missing cells, malformed records, or detached digests. |
| aggregate/tag identity → write-capable release job | Dependency/condition/permission mistakes can bypass failed gates or release the wrong commit. |
| third-party action ref → workflow execution | Mutable tags can change build/upload/release behavior without repository review. |
