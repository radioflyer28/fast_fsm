<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build intent → setup backend | Environment intent controls whether compilation is required, optional, or bypassed. |
| sdist archive → temporary build tree | Untrusted member names, types, counts, and sizes can escape or exhaust extraction. |
| sdist child build → installed evidence | A successful build can still substitute mode, omit native core, or detach from its parent archive. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-06 | Spoofing | explicit compiled build mode | high | mitigate | Re-raise compiler failures for COMPILED, reject AUTO as compiled proof, and independently require platform/native archive plus installed extension origin. |
| T-20-07 | Tampering | sdist child lineage | high | mitigate | Parent-side SHA-256, required parent fields on both children, exact intent, and duplicate/mismatch rejection. |
| T-20-08 | Elevation of Privilege | sdist extraction | high | mitigate | Normalize and contain every member path, reject links/devices/duplicates, and validate all members before any extraction. |
| T-20-09 | Denial of Service | sdist archive parser/build | medium | mitigate | Fixed member-count, per-file, and total-uncompressed bounds enforced before extraction or build. |
| T-20-10 | Tampering | selective compilation boundary | high | mitigate | Tests assert only `src/fast_fsm/core.py` is compiled and interpreted condition modules remain present/subclassable. |
</threat_model>
