<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| artifact path/archive → parent verifier | A local or downloaded archive is untrusted until resolved, bounded, parsed, and SHA-256 bound. |
| checkout/host environment → fresh installed environment | cwd, environment variables, editable metadata, symlinks, and stale extensions can spoof installed proof. |
| installed child probe → parent evidence process | Child JSON and stderr/stdout are untrusted, potentially malformed, oversized, or payload-bearing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-01 | Tampering | artifact/evidence binding | high | mitigate | Parent resolves and hashes the exact archive, independently validates archive identity, and rejects child/record SHA or tag disagreement before semantics. |
| T-20-02 | Spoofing | installed package/core origin | high | mitigate | Neutral cwd, sanitized environment, no project/config discovery, PEP 610 editable/direct-url rejection, resolved containment checks, and source/extension loader assertions. |
| T-20-03 | Information Disclosure | conformance records and errors | high | mitigate | Allowlisted scalar schema, payload sentinel tests, fixed redacted errors, bounded captured output, and exclusion of repr/args/kwargs/exception text/paths/timings from parity. |
| T-20-04 | Denial of Service | artifact and child evidence parsing | medium | mitigate | Bound archive bytes/member counts, subprocess output, JSON depth/string/record counts, and reject non-standard/malformed data before allocation-heavy comparison. |
| T-20-05 | Repudiation | suite/oracle identity | medium | mitigate | Stable scenario IDs, canonical sorted JSON, suite-definition SHA-256, semantic digest, and two-hash-seed determinism tests. |
</threat_model>
