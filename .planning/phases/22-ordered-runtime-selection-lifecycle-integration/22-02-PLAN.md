- Deterministic event-handshake tests for ordered awaits, exceptions, cancellation, exhaustion, and post-selection lifecycle failure.

<threat_model>
## ASVS Level

OWASP ASVS L1 applies. All high-severity threats below are blocking and must be mitigated by this plan's implementation and automated tests.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Awaitable user guard/state hook → async selector | Caller code may suspend, raise, cancel, or mutate its own environment while the machine retains a captured candidate set. |
| Async selector → owned lifecycle | One selected candidate crosses into synchronous and awaited callbacks under per-machine loop/task ownership. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-22-05 | Tampering | async candidate ordering | high | mitigate | Await one candidate and one eligibility stage at a time in stored order; event-handshake tests prove no overlap, speculation, or lower-candidate work after winner/exception. |
| T-22-06 | Denial of Service | cancellation and ownership release | high | mitigate | Route cancellation to the one existing owned boundary, finalize once, release in `finally`, bare re-raise, and prove the next operation can acquire ownership. |
| T-22-07 | Repudiation | async exception/exhaustion finalization | medium | mitigate | Preserve reached stage/cause/commit truth in one result and isolate observer failures without replacing the original outcome. |
| T-22-08 | Tampering | captured source and target identity across awaits | high | mitigate | Capture source/slot before awaiting, retain the winner's exact target-specific handler, and test that no later live-state reread influences permission or lifecycle selection. |
</threat_model>
