<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Installed child process → parent verifier | Child JSON is untrusted and could be malformed, oversized, digest-tampered, or payload-bearing. |
| Checkout/source → claimed clean baseline | A stale native shadow could contaminate the source record. |
| Wheel path → temporary snapshot → installed runtime | The archive could be swapped or the runtime could import a different package/core. |

| T-25-03 | Tampering | source/native origin and installed artifacts | high | mitigate | Require non-destructive source preflight, private archive snapshot, SHA-256 recheck, neutral venv/cwd, absolute origin, expected mode, loader, and architecture before accepting semantics or performance. |
