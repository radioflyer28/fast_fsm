## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller text → diagram/Markdown grammar | Untrusted labels can become comments, directives, aliases, links, or fence terminators. |
| caller payload → redactor/LogRecord/handlers | Raw runtime values cross an explicit application redactor boundary but must never reach records by default. |
| candidate checkout → verification tree | Stale native artifacts or missing overlays can falsify parity evidence. |
