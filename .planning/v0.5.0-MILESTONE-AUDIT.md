The installed-artifact oracle explicitly checks final-vs-sink, synchronous internal/external self-transition, rejection, and generic sync/async output grammar. It does **not** by itself prove every Phase 30 persistence and Phase 31 diagnostic projection inside installed wheels, nor async final/internal/rejection rows in those wheels. Separate pure/native tests cover those behaviors. This is a proof-scope warning, not an observed failing artifact; any claim of full installed-wheel coverage for those additional surfaces needs expanded evidence.
