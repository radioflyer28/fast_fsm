<interfaces>
Preserve these existing contracts while redesigning the public seam:
- Every Condition.check method and wrapped callable accepts and forwards *args, **kwargs and returns GuardResult.
- Sync dispatch closes/rejects awaitable guard results; async dispatch awaits them sequentially.
- Compound wrappers short-circuit left-to-right, reject active cycles, and permit acyclic shared DAGs.
- add_transition is the canonical candidate registrar; lower exact integer priority wins and eligibility rejection falls through only within the local immutable group.
- conditions.py and condition_templates.py remain interpreted; only core.py crosses the mypyc boundary.
- Public symbols require deprecation in a minor release and cannot be removed before the next major release.
- Existing caller-owned changes and the three commits already ahead of origin/main must be preserved; stage only the files named by this plan.

New timing contract:
- after=N is eligible when elapsed time in the source state is greater than or equal to N.
- within=N is eligible only while elapsed time in the source state is strictly less than N.
- Supplying both requires after &lt; within, creating a non-empty half-open interval [after, within).
- Durations are finite, non-negative exact built-in int/float values excluding bool.
- The clock defaults to time.monotonic, is injectable for deterministic tests, and returns a finite non-Boolean built-in number that must not precede the committed state-entry timestamp.
- One clock value is captured before evaluating any candidate or awaiting any guard in a single selection attempt; untimed singleton dispatch must retain its direct path without a clock read.
</interfaces>
