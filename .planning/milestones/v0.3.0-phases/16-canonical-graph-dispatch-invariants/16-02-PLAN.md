## ASVS Target

OWASP ASVS Level 1 applies. In-process condition objects and trigger context are untrusted inputs; high-severity cycle/payload threats must be mitigated.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller args/kwargs -> condition context | Potentially sensitive or adversarial payload crosses into guard evaluation. |
| wrapper graph -> recursive detector/evaluator | Built-in wrappers may hide async leaves or contain cycles/shared nodes. |
| sync API -> async API | Equivalent public operations currently prepare and evaluate inputs differently. |
